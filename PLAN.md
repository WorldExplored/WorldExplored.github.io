# Aero Research Habitat

## Architecture
Next.js 16 static export on the root GitHub Pages user site. React 19, strict TypeScript and Tailwind 4. Preserve the scaffold's shadcn button and utility. Native HTML dialog enhances anchor navigation on desktop; mobile follows the same sections in document flow. No server or visitor API requests.

## Content topology
Identity and direct public evidence first; four original scenic landmarks; persistent five-item dock; a readable vertical field guide with work, research, education, about, contact and one building statement. All copy and verified contribution metadata live in src/content/profile.ts. Primary content is present in exported HTML. Author log and co-developed work have separate attribution.

## Checkpoints
1. Inspect references and local instructions; verify public facts; persist design system.
2. Complete original landscape, glass controls, semantic content and hash navigation. Run lint, typecheck and build.
3. Inspect four required viewport screenshots. Record and fix findings.
4. Perform two genuine refinement passes, saving iteration-02 and iteration-03. Verify keyboard, history, mobile, reduced motion, static assets and metadata.
5. Review all changes; commit only intended files; create public repository; deploy through official Pages Actions. Test live URL and record deployment evidence.

## Validation
Check 390×844, 768×1024, 1024×768, 1440×900, plus 375px and landscape. Validate every navigation source, hash, close path, Escape, Tab trap, focus return, browser Back and external URL. Audit exported content for excluded terms, template assets and private metadata. Recheck production logs and first-party asset responses.
