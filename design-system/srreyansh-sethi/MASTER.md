## Focused guidance synthesis
Glassmorphism: deliberate transparency, separated foreground, controlled blur. Skeuomorphism: consistent lighting, layered depth, tactile press; avoid textures behind body copy. Organic biophilic: curved landforms, believable green and sky blue, natural shadows. UX: 4.5:1 normal text, keyboard access, skip link, no hover-only actions, 44px targets, no overflow, stable Back behavior. Motion: 180–220ms state response, restrained environment, reduced-motion and manual pause. GSAP search supplies timing guidance only: use native CSS, keep content visible and skip a new library. Next.js: use metadata API, static export, reserved responsive image dimensions; reject dynamic rendering advice incompatible with Pages.
