## ryOS — https://os.ryo.lu/
Observed the desktop, Finder opening, task dock and narrow viewport. The dock is spatially stable; glossy icon silhouettes and layered panel shadows create depth. Windows have clear close/minimize/maximize states. A narrow viewport clips desktop-style window content and floating notices, illustrating why this portfolio needs a separate mobile composition.
