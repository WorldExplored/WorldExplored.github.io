# Living cloud specification
Target files: clouds.ts, AmbientSystem.tsx cloud subsystem, new cloud surface module if needed, scripts/clouds-hover.test.tsx and focused new cloud tests. Interaction: independent time-driven wind layers with local pointer deformation; paused freezes.
Baseline screenshot is private work/living-world/before/1440-overview.jpg. Natural cloud photograph is private work/living-world/research/gull-cloud-reference.jpg. Bright rounded tops, cool blue-gray undersides, contiguous irregular lobes; foreground must no longer expose individual ellipsoids or flattened banks. Build smooth merged volume geometry from an implicit field (metaball/marching surface or equivalently continuous mesh), generated once and reused. Use soft internal shading and fine irregular relief, not extra sphere instances. At least five visibly different profiles with depth; only distant atmospheric thin. Distribute all compass directions, city and beyond beacon (-76,-36). Three coherent x/z wind layers. No reset within visible frustum; prefer globally continuous bounded paths with both axes or wrap only at invisible world perimeter. Interaction deforms a local region without shrinking whole cloud, stable ray ownership; no scale jumps. Preserve quality population counts and public API compatibility where sensible. Geometry/material resources remain stable across selection, frames and tier changes. No content or UI changes. No new dependency. Add meaningful tests for depth, diagonal travel, long-time continuity, local response, freeze and resources. No commits until visual review. Root integrates files, renders and iterates.
